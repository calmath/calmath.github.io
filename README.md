# S&C Checklist

A mobile-friendly, tap-to-check S&C session checklist, published via GitHub Pages so it's reachable without any login.

**Source of truth:** `athlete-profile.md` in the private [`calmath/running`](https://github.com/calmath/running) repo — Weekly Structure → "S&C Session Content — A / B templates". This repo is a public, generated mirror of that template (finalised 10/09/2026), kept in sync by hand whenever the routine changes there.

Nothing sensitive lives here by design — no training log data, no personal identifiers beyond the routine itself.

Live page: https://calmath.github.io/sc-checklist/ (once Pages is enabled: Settings → Pages → Deploy from a branch → `main` / `/root`).
